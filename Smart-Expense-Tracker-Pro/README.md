# Smart Expense Tracker Pro

## Project Overview

Smart Expense Tracker Pro is an advanced full-stack personal finance management platform built using React, Node.js, Express, PostgreSQL, and Prisma. The application helps users manage income, expenses, budgets, recurring transactions, and financial analytics through an interactive dashboard.

* Income & Expense Management
* Budget Tracking
* Recurring Transactions
* Multi-Currency Support

* Financial Dashboard
* CSV Import

* Secure REST APIs
